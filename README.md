A program that writes a short poem about agency — the power to ask and to be given — to `/output/entry.txt`.

## Run it

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Pure Node 22 standard library, no network, deterministic: two runs write byte-identical text files.
